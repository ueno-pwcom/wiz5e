# 3Dダンジョン探索RPG（SRD 5.1準拠） 機能仕様書

## 1. プロジェクト概要

### 1.1 目的・コンセプト
本ドキュメントは、古典的なウィザードリィスタイルのグリッドベース3Dダンジョン探索RPGの機能仕様を定義するものである。
ゲームシステム・データ・ルールエンジンには **SRD 5.1（D&D 第5版 システムリファレンスドキュメント）** を採用し、レトロダンジョンクローラーの緊張感と5eルールの戦略性を融合させたシンプルな最小限の構成（MVP）を目指す。

### 1.2 主要ターゲット・特徴
* **パーティ編成**: 5人パーティ（前衛最大3名 / 後衛）
* **戦闘・判定ルール**: SRD 5.1準拠（d20対抗判定、ダイスロール、AC、属性ダメージ）
* **成長システム**: レベルアップ時のHP上昇はダイスロールを行わない固定値上昇
* **拡張性**: クラス・呪文・モンスター・マップデータを外部JSONで管理し、後からのコンテンツ追加が容易な設計

---

## 2. システム構成・アーキテクチャ

### 2.1 データ駆動設計 (Data-Driven Architecture)
各種データ（クラス、呪文、モンスター、ダンジョンマップ、宝箱/罠、街のショップ等）は独立したJSONファイルで定義し、プログラムコードから参照・ロードする構造とする。

```
[ Game Engine / Rules Logic (SRD 5.1) ]
       ├── classes.json        (クラス定義・成長値)
       ├── spells.json         (呪文データ)
       ├── monsters.json       (モンスターデータ)
       ├── dungeon_floor_1.json(マップ・エンカウント)
       ├── chests.json         (宝箱・罠・ドロップ)
       └── town.json           (拠点施設・ショップデータ)
```

## 3. キャラクター & パーティ仕様

### 3.1 5人パーティシステムと陣形
パーティは5人で編成され、前衛（最大3名）と後衛に分けられる。

```
【敵 陣 営】
    ↕ （交戦距離）
【前衛】 [1人目] [2人目] [3人目]  ← 近接攻撃を受けるメイン壁役
【後衛】 [4人目] [5人目]          ← 近接攻撃対象外（間合い/呪文/射撃のみ到達）
```

* **前衛（Front Row）**: 最大3名。敵の近接攻撃（Reach 5ft）の標準的な対象。
* **後衛（Back Row）**: 前衛が存在する限り、敵からの近接武器攻撃を受けない（リーチの長い武器・遠距離攻撃・範囲呪文は受ける）。

### 3.2 基本能力値 (Ability Scores)
SRD 5.1に準拠する6つの基本能力値を保持する。
* **STR（筋力）**: 近接攻撃・威力を決定
* **DEX（敏捷力）**: AC、イニシアチブ、〈盗賊の道具〉判定、DEXセーヴ
* **CON（耐久力）**: HP上昇値、CONセーヴ（毒・麻痺等）
* **INT（知性）**: ウィザード呪文能力、〈捜査〉技能
* **WIS（叡智）**: クレリック呪文能力、〈知覚〉技能・受動知覚
* **CHA（魅力）**: 寺院・ショップでの価格交渉等（将来拡張）

### 3.3 クラス設計と成長（初期4クラス）
初期実装として主要4クラスを設定し、レベルアップ時のHP上昇は固定値とする。

| クラス | ヒットダイス | レベルアップ時増加HP | 主な役割・技能 |
| :--- | :--- | :--- | :--- |
| **ファイター** | d10 | `6 + CON修正値` | 重装鎧の前衛壁役・物理アタッカー |
| **ローグ** | d8 | `5 + CON修正値` | 罠識別・解除（習熟強化）、急所攻撃 |
| **クレリック** | d8 | `5 + CON修正値` | 回復・支援呪文、中/重装前衛・後衛 |
| **ウィザード** | d6 | `4 + CON修正値` | 範囲攻撃呪文、ユーティリティ |

* **初期HP (Level 1)**: `ヒットダイスの最大値 + CON修正値`

## 4. ダンジョン探索 & ギミック仕様

### 4.1 グリッドベース移動
* ダンジョンは1マス＝1ステップのグリッド構成。
* プレイヤー操作: 前進、後退、左回転（90度）、右回転（90度）。

### 4.2 マップデータ構造 (`dungeon_level_1.json`)
各マス（Grid Cell）は四方の壁状態と埋め込みイベント情報を保持する。

```json
{
  "map_id": "floor_01",
  "name": "地下1階：試練の迷宮",
  "width": 5,
  "height": 5,
  "start_position": { "x": 0, "y": 0, "facing": "N" },
  "grid": [
    [
      {
        "x": 0, "y": 0,
        "walls": { "N": "wall", "E": "door", "S": "wall", "W": "wall" },
        "event": { "type": "stairs_up", "target_map": "town" }
      },
      {
        "x": 1, "y": 0,
        "walls": { "N": "wall", "E": "none", "S": "wall", "W": "door" },
        "event": null
      },
      {
        "x": 2, "y": 0,
        "walls": { "N": "wall", "E": "wall", "S": "none", "W": "none" },
        "event": { "type": "chest", "chest_id": "chest_tier_1" }
      }
    ]
  ],
  "encounter_table": {
    "rate": 0.1,
    "monsters": [
      { "id": "goblin", "weight": 60 },
      { "id": "skeleton", "weight": 30 }
    ]
  }
}
```

### 4.3 探索ギミック（受動知覚 & 捜査）
1. **受動知覚（Passive Perception）**:
   * 計算式: `10 + パーティ内で最も高い〈知覚〉技能修正値`
   * 移動時、マスに設定された隠し扉・隠し罠のDCと自動比較判定。`受動知覚 >= DC` の場合に警告・発見ログを表示。
2. **能動的調査（Investigation）**:
   * プレイヤーが「調べる」実行時、`1d20 + 〈捜査〉修正値` でダイス判定。

## 5. 宝箱・罠解除システム

戦闘勝利時または探索時に出現する宝箱の処理シーケンス。

```
[宝箱発見] ──> [① 罠の識別 (捜査)] ──> [② 罠の解除 (盗賊の道具)] ──> [解錠 & 戦利品獲得]
                                   └─> (大失敗/解除失敗) ──> [罠発動]
```

### 5.1 罠の識別 (Investigation)
* **判定**: `1d20 + 〈捜査〉修正値` vs **識別DC**
* **成功**: 罠の正式名称（「毒針」「爆弾」等）を特定。
* **失敗**: 罠の種類不明（そのまま解除試行可能）。ファンブル（出目1）時は誤識別情報を表示。

### 5.2 罠の解除 (Thieves' Tools)
* **判定**: `1d20 + DEX修正値 + 習熟ボーナス`（ローグの習熟強化でボーナス2倍） vs **解除DC**
* **成功**: 罠を安全に解除し、戦利品を獲得。
* **失敗**:
  * **許容失敗（差が4以内）**: 解除失敗（再試行可能）。
  * **致命的失敗（差が5以上、または出目1）**: 罠が即座に発動。

### 5.3 代表的な罠の仕様
* **毒針 (Poison Needle)**: 解除者に `1d10` 毒ダメージ＋CONセーヴ（失敗で毒状態）。
* **爆弾 (Explosive Trap)**: 前衛全員に `2d6` 炎ダメージ（DEXセーヴで半減）。
* **アラーム (Alarm)**: 敵との連戦（即時エンカウント）が発生。
* **テレポーター (Teleporter)**: パーティ全員をダンジョン内のランダムマスへ強制移動。

## 6. 戦闘システム仕様

### 6.1 ターン制 ＆ イニシアチブ
* 戦闘開始時に全員が `1d20 + DEX修正値` を振り、イニシアチブ順に行動。
* 1ラウンド＝6秒（アクション、ボーナスアクション、リアクションを管理）。

### 6.2 攻撃 ＆ ダメージ判定（リアルタイムダイス）
1. **攻撃ロール (Attack Roll)**:
   * `1d20 + 攻撃修正値` vs **対象のAC**
   * 出目20（クリティカル）: 必中 ＋ ダメージダイス数を2倍にしてロール。
   * 出目1（ファンブル）: 自動ミス。
2. **ダメージロール (Damage Roll)**:
   * 武器・呪文固有のダイス（例: `1d8 + STR修正値`）を毎回ロールして計算。

### 6.3 呪文システム（簡易化SRD 5.1）
テンポを重視し、SRD 5.1の骨組みを保ちつつ以下の簡易化を適用する。
* **呪文準備の撤廃**: 修得呪文はスロットがある限りいつでも全種類使用可能。
* **構成要素・発動時間の簡略化**: 全呪文1アクション、コンポーネント（V/S/M）管理オミット。
* **集中（Concentration）**: 1人につき同時に1つの集中効果のみ維持可能。
* **呪文DC**: `8 + 習熟ボーナス + 呪文能力修正値`（自動対抗セーヴ判定）。

#### 代表的初期呪文データ例 (`spells.json`)
* **キュア・ウーンズ** (1Lv クレリック): 味方単体HP回復 (`1d8 + WIS修正値`)
* **マジック・ミサイル** (1Lv ウィザード): 必中力場ダメージ (`3d4 + 3`)
* **バーニング・ハンズ** (1Lv ウィザード): 敵前衛全体に炎ダメージ (`3d6` / DEXセーヴで半減)

## 7. 拠点（街）システム仕様

ダンジョンから帰還した際の回復・成長・買い出しを行う安全地帯。

### 7.1 施設一覧
1. **ギルド (Party Guild)**:
   * キャラクター新規作成（ポイントバイ/標準配列による能力値割り振）
   * 5人パーティ編成・前後衛入れ替え
   * 訓練所（必要XP達成時のレベルアップ処理）
2. **宿屋 (Inn)**:
   * **馬小屋（無料）**: ヒットダイス消費による回復のみ（スロット回復なし）
   * **相部屋（5 sp/人）**: 長休止適用（HP・全スロット全回復、ヒットダイス半分回復）
   * **個室（2 gp/人）**: 長休止効果 ＋ 次の探索時に一時的HP `+5` 付与
3. **商店 (Merchant Shop)**:
   * 装備品・消費アイテムの売買
   * 未識別アイテムの鑑定（一律 100 gp）
4. **寺院 (Temple)**:
   * 状態異常の治療（50 gp）
   * 死亡キャラクターの蘇生（`レベル × 100 gp`）

### 8.2 テキストログとカラーコーディング
進行状況およびダイスロールの出目をリアルタイムにログ領域へ出力する。

* **文字色ルールの定義**:
  * **白**: 通常メッセージ・移動テキスト
  * **青**: 味方の攻撃命中・呪文成功・罠解錠成功
  * **緑**: HP回復・状態異常治療
  * **赤**: 敵の命中・被ダメージ・罠発動
  * **オレンジ**: クリティカルヒット（出目20）
  * **黄**: 宝箱ドロップ・ゴールド獲得
* **ダメージログ表記例**:
  * `バルドの攻撃！ [1d20+5: 19 vs AC 15] 命中！ ゴブリンに 6 (1d8+2) の斬撃ダメージ！`
